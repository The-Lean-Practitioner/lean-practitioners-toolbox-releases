# Lean Practitioner's Toolbox

Create SIPOC diagrams, Fishbone (Ishikawa) diagrams, X-Y Matrices, and Value
Stream Maps without flowcharting skills. Structured text authoring drives the
diagram — you describe the process, the tool draws it.

This repository hosts downloadable releases only. Source code is not public.

---

## Status

**Beta.** This software is under active development and is provided for
evaluation purposes. Expect rough edges. Please report problems via the
[Issues](../../issues) tab.

## Requirements

- macOS on Apple Silicon (M-series). Intel Macs are not supported.
- Windows builds are planned but not yet available.

## Installation

1. Download the `.dmg` file from [Releases](../../releases).
2. Open the downloaded file.
3. Drag **Lean Practitioner's Toolbox** to your Applications folder.
4. Launch it from Applications.

On first launch macOS may ask you to confirm that you want to open an
application downloaded from the internet. Click **Open**. This is normal.

The application is signed and notarized by Apple. If you see a message saying
the app is damaged or cannot be opened, that indicates a problem — please
open an Issue and include the exact wording.

## Reporting Problems

Use the [Issues](../../issues) tab. Helpful details:

- What you were doing when the problem occurred
- What you expected versus what happened
- Your macOS version (Apple menu → About This Mac)
- The app version (from the release you downloaded)
